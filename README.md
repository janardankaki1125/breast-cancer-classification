# Breast Cancer Classification

Supervised binary classification project to predict malignant vs benign breast tumors.

## Goal
- Data preprocessing and scaling
- Train/Test split + 5-fold Cross Validation
- Compare two models: Logistic Regression vs Random Forest
- Report Accuracy, Precision, Recall, F1-Score, ROC-AUC

## Best Model
**Logistic Regression** (Test Accuracy: ~0.9737, ROC-AUC: ~0.9954)
